## 👨‍💻 À propos

Développeur polyvalent, je couvre l'ensemble du cycle de vie d'une application : du développement (web, mobile, backend) au déploiement automatisé, à l'orchestration et à la sécurisation.

| Domaine | Ce que je fais |
|---|---|
| 💻 **Développement** | Applications web, mobile et APIs backend |
| ☁️ **DevOps & Cloud** | Infrastructure AWS, conteneurisation Docker, orchestration Kubernetes, pipelines CI/CD, monitoring Grafana |
| 🔐 **Sécurité offensive** | Tests d'intrusion et audits de sécurité, dans un cadre légal et autorisé |
| 🤖 **IA appliquée** | Utilisation quotidienne d'assistants IA pour le code, le débogage, la documentation et l'automatisation, avec relecture et validation systématiques |
